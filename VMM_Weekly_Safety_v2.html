OneDrive / Data Storage
📁 How Data Flows:

📱 Store opens HTML on mobile → fills checklist offline (GPS auto-detects store)
🌐 On Submit (needs internet) → JSON written to OneDrive via Microsoft Graph API
🔄 If offline at submit → saved locally in browser, synced on next internet connection
🖥 Admin reads OneDrive submissions → aggregated dashboard
📧 Outlook VBA (Windows) reads OneDrive tracking CSV for email automation

⚠️ Requires Azure AD App Registration for Graph API file access.
Register at portal.azure.com → App Registrations → Files.ReadWrite permission.
