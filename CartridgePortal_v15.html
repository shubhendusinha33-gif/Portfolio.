🏗️ Architecture Info

Why No Mail Sent?

This portal is a standalone offline HTML file. It cannot send emails directly from the browser. In production deployment on SharePoint, email is triggered via:

Browser → SharePoint REST API
→ Power Automate HTTP trigger
→ Office 365 Send Email action
→ 700 Store Managers (TO)
→ RFM / ZFM / Central Ops (CC)
→ Reminder scheduler (+24h, +12h, +12h)
To test today: Enable Test Mode in Admin tab → the "Send Mail" button will open your mail client (Outlook) with the email pre-filled, addressed only to you. You can send it manually to verify the content.
Power Automate URL Config: Once deployed, paste your HTTP trigger URL in Admin → Email Settings. The portal POSTs the month and recipient list to that URL.
